Student-Result-Management-System

## 1.Project Requirements

Hardware Requirements
Computer or Laptop
Minimum 4 GB RAM
Minimum 500 MB free storage
Keyboard and Mouse

Software Requirements
Python 3.x
VS Code or any Python-supported IDE
Command Prompt / Terminal
Git and GitHub

## 2.⁠ ⁠Functional Requirements

The system should be able to:

Add student details such as name, roll number, and marks.
Store marks for different subjects.
Calculate total marks.
Calculate percentage.
Display the students result.
Search for a student using the roll number.
Update student records.
Delete student records.
Display the pass/fail status.

## 3. Non Functional Requirements.

The system should be simple and user-friendly.
Result calculations should be accurate.
The program should execute quickly.
The system should be easy to maintain and modify.
The program should run through the command line.
The project should not require GUI-based setup.

## 4.⁠ ⁠Python Requirements

The project uses standard Python libraries only.

No external Python packages are required.

Python Version

Python 3.x

Required Modules
-os – for basic file and directory operations.
-json – for storing and managing student records.

## 5.⁠ ⁠Execution Requirements

The project should be executable from the command line using:

python main.py

The user can then select options from the menu to manage student records and view results.
